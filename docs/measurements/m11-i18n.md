# M11-T3 – nyelvesítés mérés

Mérve 2026-11-21, élő GUI a `:50129` daemonon.

## Felépítés

- `ferrent_gui::i18n`: `Lang { Hu, En }`, `install(lang)`, `t(english)`.
  Az **angol szöveg a kulcs**; a `locales/hu.toml` adja a fordítást, a
  hiányzó kulcs angolra esik vissza (nem hiba).
- A katalógus `include_str!`-mal a binárisba kerül; a TOML-t egyszer
  parse-oljuk (`LazyLock`). Hibás katalógus → üres map, a GUI angolul indul
  (nem panic — ezt a mérés fogta: egy duplikált `STATUS` kulcs megölte az
  indulást, amíg `expect` volt).
- Nyelv: `FERRENT_LANG` env → `gui.toml` `lang` → **default `hu`**.

## Lefedettség (2026-11-21)

A GUI *chrome*-ja teljesen átment a katalóguson:

- sidebar: Összes torrent, Letöltés, Mozgatás, Seedelés, Sorban,
  Szüneteltetve, Aktív, Hiba, CÍMKÉK, Beállítások, Szerverek, Lecsatlakozás;
- tábla-fejlécek: ID, NÉV, CÍMKE, MÉRET, MENTÉSI ÚT, ÁLLAPOT, HALADÁS, LE,
  FEL, SEED, PEER, ETA;
- Details fülek: Általános, Fájlok, Peer-ek, Trackerek, Aktivitás;
- Settings fülek és a fő címkék/hintek, üres állapotok, RSS fejléc,
  megjelenés (Téma/Akcentszín).

**Még angolul (ismert hiány):** a sorok állapotszava (`seeding`,
`downloading`), a formázott számlálók (`1 disk`, `12.1 GiB free`, `connected`,
`5 active`, `13 torrents`) — ezek paraméteres fordítást igényelnek
(`t_fmt`), a következő körben.

## Mérés

- `FERRENT_LANG` nélkül: magyar UI (`docs/measurements/m11-i18n-hu.png`).
- `FERRENT_LANG=en`: angol UI (`docs/measurements/m11-i18n-en.png`),
  ugyanaz a nézet.
- Tesztek: `hungarian_is_the_default_and_english_falls_back`,
  `language_codes_round_trip`, `the_catalogue_is_not_empty` (90 kulcs).
- A katalógus-duplikátum okozta indulási panic után a betöltés toleráns.

## CLI

A `ferrent-cli` help/hiba szövegei **még nem** mennek át a katalóguson
(clap-szintű lokalizáció külön munka); a `--json` kimenet amúgy is gépi.
